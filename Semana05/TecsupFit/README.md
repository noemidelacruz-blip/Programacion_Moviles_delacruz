# TECSUP Fit - Aplicación Mobile

Aplicación móvil desarrollada en **Android / Jetpack Compose** para la gestión y reserva de clases deportivas en TECSUP.

---

## Integrantes
- **Noemi De La Cruz**

---

## Características Principales
- **Inicio**: Consulta de clases disponibles por horario y sala.
- **Detalle de Clase**: Información extendida de cada disciplina con cupos disponibles.
- **Confirmación de Reserva**: Feedback visual del cupo reservado exitosamente.
- **Mis Reservas**: Listado de clases confirmadas y opción de gestión.
- **Rutinas**: Sección dedicada al seguimiento de planes de entrenamiento.
- **Perfil**: Datos del usuario (Noemi De La Cruz) con métricas de clases asistidas y racha activa.
