# AuthFirebaseApp 🌸

Aplicación móvil desarrollada en **Android Studio** utilizando **Jetpack Compose** e integrada con **Firebase Authentication** (base de datos de autenticación en la nube) para la gestión segura de usuarios.

**Desarrollado por:** Noemí de la Cruz / Tecsup

---

## Integración con Firebase (Nube)

La aplicación utiliza la infraestructura en la nube de **Firebase Auth** para:
* **Autenticación en tiempo real:** Verificación de credenciales guardadas en la nube.
* **Registro de usuarios:** Creación e inclusión de nuevos usuarios directamente en la consola de Firebase (`createUserWithEmailAndPassword`).
* **Control de sesiones:** Gestión persistente del estado del usuario (inicio y cierre de sesión).
